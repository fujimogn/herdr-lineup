## P1 — original priorities

### 1. BUG-04 — transient reconnect failure exits the daemon

- **Target:** `src/daemon.rs:322-347`, `src/socket.rs:122,165`.
- **Problem/condition:** After a refresh error, either `reconnect_same_endpoint()?` or `check_transport()?` can fail once and exit the daemon without clearing. Tokens then expire and do not return until another focus event. A replaced endpoint should still cause exit.
- **Evidence:** **Code**, confirmed again by the Commander at `daemon.rs:327-328`. OpR **measured** Linux `EAGAIN` when the listen backlog was full; macOS remains unverified. Frequency and user impact are **estimated**.
- **Improvement:** Keep the loop alive on transient reconnect and ping failures; exit only when endpoint replacement is verified. This matches `openspec/specs/daemon-lifecycle/spec.md:24-25,49-52`.
- **Priority / effort / risk:** P1 / S–M / low. **Verification:** Force one reconnect and one ping failure with a fake socket, verify retry and later publish; verify replaced endpoint still exits and normal stop clears. **Reported by:** OpR N2. **Status:** Shipped in `a32d4bb`, `0a5d2d3`, and `4782f77`: transient failures retry; a socket missing beyond token TTL exits; ensure waits for the replaced endpoint's old owner.

### 2. BUG-03 — Grok test depends on a 40 ms global timeout

- **Target:** `src/quota_grok.rs:638-675` (especially `:647`, `:655`).
- **Problem/condition:** The test's success and later 401/403/500 response must both arrive inside the global 40 ms timeout; a slow response is classified as transient, breaking the authentication assertion. CI green gates releases.
- **Evidence:** **Code** mechanism confirmed by the consolidator and Commander. **Measured:** OpR saw 2/8 serial, 1/6 parallel, and 2/40 isolated failures; consolidation saw 2/60 at load average 33–47; Commander saw 0/340 across isolated, 16-way parallel, and CPU-loaded runs. CI incidence is unknown.
- **Improvement:** Use a generous timeout for cases that assert non-timeout behavior; keep a deliberately short timeout only in the timeout-specific test.
- **Priority / effort / risk:** P1 / S / low, test-only. **Verification:** Repeat the targeted test under serial, parallel, and loaded conditions, then run the CI test suite. **Reported by:** OpR N1. **Status:** Shipped in `a3a2a91`: non-timeout cases no longer depend on the short timeout.

### 4. BUG-05 — stop can race control worker completion and skip clear

- **Target:** `src/daemon.rs:306-320,391-394`.

- **Evidence:** **Code**, with a timing-window **estimate**; `openspec/specs/daemon-lifecycle/spec.md:66-67` requires clearing a reachable endpoint.
- **Improvement:** Recheck shutdown before returning the worker-exit error.
